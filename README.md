# 个人荣誉档案・奖项展示网站（李俊晖）

简洁美观的奖项展示网站，分为「技能证书」与「荣誉奖项」两类，**一个奖项对应一张证书 / 奖状图片**，点击卡片可放大查看。部署到 GitHub Pages 后，别人扫二维码即可浏览。

## 特色功能：自助上传

不用改代码、不用懂编程，直接在网页上维护你的档案：



1. 打开网站，点击页面底部 **「管理我的档案・上传证书与奖状」**；

2. 在管理面板里**新增 / 编辑 / 删除 / 排序**条目，并**上传证书或奖状照片**（图片会自动压缩，不用担心文件太大）；

3. 改完后点 **「导出页面文件」**，浏览器会下载一个新的 `index.html`；

4. 把这个文件**替换到 GitHub 仓库**（覆盖原来的 index.html），等待 1–2 分钟，所有人扫码看到的即是新内容。

> 原理说明：纯静态网页无法直接改写 GitHub 上的文件，所以采用「在浏览器里编辑 + 导出文件 + 替换到仓库」的方式。导出的文件已把上传的图片内嵌进去，可完全脱离 
>
> `assets`
>
>  文件夹独立使用。

## 目录结构



```
jaingxiang/

├── index.html   # 网站主体（含管理面板与数据）

├── assets/      # 内置示例占位图 + 二维码组件 qrcode.min.js（**请保留此文件**，删除后二维码功能失效）

└── README.md
```

## 手动改数据（可选）

打开 `index.html`，找到 `<script id="site-data" type="application/json">` 标签，里面是全部数据（姓名、座右铭、证书列表、奖项列表）。按 JSON 格式修改即可；每条的字段：



* `title` 证书 / 奖项名称

* `issuer` 颁发机构

* `date` 获得时间（格式 `2025-06`，显示为「2025 年 6 月」）

* `no` 证书编号（没有可留空）

* `desc` 一句话说明（没有可留空）

* `img` 对应图片：`assets/` 里的文件名，或直接填网络图片地址

* `example` 示例标记（真实数据删掉该字段即可）

## 部署到 GitHub Pages（扫码访问）



1. **创建 GitHub 仓库**：登录 [github.com](https://github.com) → 右上角 `+` → New repository → 填仓库名（如 `honors-site`，**建议勾选 Public**，这样别人无需登录即可访问）→ Create repository。

2. **推送本文件夹**：在项目文件夹内打开终端，依次执行：



```
git init

git add .

git commit -m "个人荣誉档案网站"

git branch -M main

git remote add origin https://github.com/<你的用户名>/honors-site.git

git push -u origin main
```

（把 `<你的用户名>/honors-site` 换成你自己的仓库地址；不会用命令行的话，也可以直接把本文件夹里的文件拖到 GitHub 网页上的仓库页面上传。）



1. **开启 Pages**：进入仓库 → `Settings` → 左侧 `Pages` → Source 选 **Deploy from a branch** → Branch 选 **main** / 目录选 **/(root)** → Save。等待 1–2 分钟。

2. **访问网址**：`https://<你的用户名>.github.io/honors-site/` —— 这就是别人扫码要看的地址。

> 之后每次更新：在网站里改好 → 导出 
>
> `index.html`
>
>  → 到仓库页面点开该文件 → 右上角铅笔编辑 → 全选替换内容保存（或直接重新上传覆盖），等待片刻即可。

## 生成二维码

网站已内置二维码功能：

* 部署后打开网站，点击右下角的**二维码按钮**，即可生成当前网址的二维码；
* 把二维码发给别人（打印进简历、名片，或发群聊 / 朋友圈），手机扫一扫即可打开本页；
* 本地以文件方式打开时无法生成有效二维码（本地文件没有固定网址），部署到 GitHub Pages 后再使用即可；
* 也可用外部工具（如 [草料二维码 cli.im](https://cli.im)）把网址转成二维码，效果相同。

## 可选：绑定自定义域名

在仓库 `Settings → Pages → Custom domain` 里填入你自己的域名，并在域名服务商处添加一条 CNAME 解析指向 `<你的用户名>.github.io` 即可。
